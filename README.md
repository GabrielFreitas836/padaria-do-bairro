# Padaria do Bairro Online

**Projeto de Estudo:** vitrine e sistema de pedidos de uma padaria fictícia, desenvolvido ao longo
de uma apostila de desenvolvimento web gerada pelo Claude.

## Funcionalidades

- Vitrine de produtos responsiva
- Carrinho de compras com desconto e frete grátis
- Carrinho salvo no navegador (localStorage)

## Tecnologias

HTML, CSS, JavaScript

## Como executar

1. Abra a pasta do projeto no VS Code.
2. Clique com o botão direito em `frontend/index.html`
3. Escolha **Open with Live Server**.
